# MAINL cold-build text context

These two historical text inputs are declared context, not newly source-owned functions.

- `mainl.@l` preserves the original 35 project object slots and toolchain startup/library response. The stage helper replaces only the vector object slot with the maintained vector_far producer.
- `flake.asp` is the historical generated sprite include, stored canonically as 1,239 LF bytes and explicitly staged as 1,281 CRLF bytes. Regenerating it from BMP is not claimed.
- `object_graph.json` records the reviewed original first-use GAME/BINARY flags and maintained providers. It is checked against source composition, not used to substitute compiled objects.

The source stage reads no project OBJ, EXE, MAP or target bytes. Frozen ReC98 archive headers, declarations, macros, root DATA/BSS and original scanner codestring remain context. TC4 C0L.OBJ, EMU.LIB, MATHL.LIB and CL.LIB are separately declared toolchain inputs, not project source credit. CRT replacement is a separate proof lane.

Both historical text inputs are stored with canonical LF endings under the repository text policy. The source stage explicitly converts them to CRLF, including the response before token extraction, so a fresh Git checkout recreates the reviewed native source identities.
