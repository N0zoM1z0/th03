## Negative experiments: source-equivalent does not imply TC4 byte-equal

- Kana: `af737b` attempted a direct signed 8-bit expression instead of
the original AL subtraction for cloud angles. Real CODE differed and
the hardware/ABI-specific AL operation remains.
- Yumemi Extra Attack: `af738b` replaced two explicit `pid_current == 1`
clip-side tests with truthiness; original CODE changed. The original
byte comparison was restored, but the named lifecycle and natural loop
counters passed in `af738c`.
- Enemy hitbox/chain: `af739a/b/c` pinpointed the 3-byte difference from
using `if(!(hits & 1))` for the original `if((hits & 1) == 0)`.
`af739d` retained the signed local-index and chain-threshold recovery
while restoring the exact direct memory-test encoding.
- MAIN handoff: `af740b` showed that converting the original large-model
near/far-pointer and four-byte vararg null C-style casts to modern
`reinterpret_cast` / `static_cast` was **rejected at compile time by TC4**.
`af740c` preserved the original `execl` ABI and accepted a natural
volatile VSYNC polling loop.

None of these rejected variants are claimed to have passed; their real
native scratch outputs and logs remain retained. No output-byte
patching, target-substitution, artificial CODE padding or full cold
replay was used.
