# MAINL root consumed-source proof

The root source checkpoint is followed by two actual fresh TASM root assemblies
and TLINK links. Both consume the maintained `src/mainl/root/root.asm` include.
Other objects are explicitly retained contextual inputs, including the already
proved graphics split. This is a root/link hybrid repeat, not a whole cold build.

The first build uses MRT01 and the second MRT02. Each root object, executable
and MAP is newly produced; none of those outputs is copied into the fresh tree.
The second run preserves declared observed first-input mtimes before compilation.
Full raw root OBJ, EXE and MAP must match between the two actual runs. No output
normalization, relocation sorting, target-byte injection or object rewriting is
performed. Both phases use one CPU, nice >=10 and 90-second owned native limits
with 15-second cleanup allowances.

The nine procedures (2,470 bytes) plus nine symbolic switch words (18 bytes)
match the decoded target over 095F:0186..0B3D. The 114 scoped relocations have
identical membership but 112 ordered-index differences. This is not original
ordered-relocation equality. The previous 9,483 scoped bytes are preserved by
full raw executable identity, giving 11,971 scoped target-equal bytes. Prior
snow/staff model results are reused only with that pinned complete image and
its verified receipt, not re-executed implicitly.

The root target and current images each execute the existing 456-call model
matrix (455 observation records). All observed results agree, including the
intentional nonterminal clock/menu budgets and modeled exec handoff. Foreign
libraries, device operations, file assets, process execution and asynchronous
clock updates remain explicit models. `scripts/replay_th03_mainl_root_link.py`
rechecks consumed-source expansion, both native receipts and raw repeat products,
then reruns the root matrix without invoking the native toolchain.

The single existing `th03-mainl-decoded-root` unit can now be source-present;
its size and boundary are unchanged, with no new denominator units. Exact
acceptance remains zero. Full MAINL still differs by DATA byte 0E3F:0849
(target 90, candidate 00), and global relocation membership equality (677)
does not close the 461 ordered-index differences. Packed canonical-file mapping,
whole cold dependencies and packaging remain separate open requirements.

The historical review's ten PI caller differences are retained as observations
of its older cached products. They are absent here because the original scanner
source context restores the proper PI layout, not because root calls were patched.
