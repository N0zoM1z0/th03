# MAINL archive/file maintained-source checkpoint

This proposal localizes 25 complete symbolic provider includes into
`src/mainl/archive_io/`, consumed at their original root include positions by
`scripts/lib/mainl_archive_io_source.py`. Full expanded statement identity,
unique consumption, instruction/branch/dispatch mutation rejection and
no-overwrite staging pass five source-only tests. This checkpoint does not
claim native compilation, runtime replay, source-present promotion or exact
acceptance. MAINL remains 65/145 source-present units /20,671 bytes, exact0,
until the separate fresh native/repeat and runtime evidence is installed.

## Preserved contracts and explicit boundaries

- FILE retains inactive handles, final DOS carry semantics, short/overreported
  counts, buffer/output aliases, inherited DF and direct-write FFFF success.
  DOS_FILESIZE retains end-seek and restore-error quirks rather than imposing
  a corrected interface.
- PFOPEN retains GAME=3 directory lookup and failure behavior. Its existing
  MAIN overlay is a contextual dependency, not fresh MAIN ownership.
- PFGETC/RLE/plain/keyed reads preserve native indirect calls, cached run state,
  XOR key, 32-bit wrap and the distinct near/far stack cleanup. PFREAD clears
  DF; BREAD does not and uses signed size acceptance.
- PFINT21 retains its mutable CS saved vector, reentrancy byte and dispatch
  sentinel, the actual interrupt frame and IRET. The hook model executes the
  native archive/buffer chain while high-level install file calls and heap/DOS
  remain explicit interfaces. The separate file model executes native file
  routines. These are bounded observations, not one combined real DOS run.

Historical detailed observations remain in MAINL_FILE_REVIEW.md,
MAINL_PFINT21_REVIEW.md, MAINL_PFOPEN_REVIEW.md, MAINL_PFREAD_REVIEW.md and
MAINL_BUFFER_REVIEW.md. Their old cached proof is not represented as a fresh
current-carrier execution. The buffer prose arithmetic is corrected separately:
374 buffer body bytes +4 gaps +26 contextual DOS-open bytes =404, not504.
