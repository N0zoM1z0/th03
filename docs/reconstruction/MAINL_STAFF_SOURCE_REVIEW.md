with the already maintained 355-byte graphics producer they partition the full

These are instruction sources, not raw-byte arrays. Original labels are retained
for stable root references; per-procedure comments explain behavior and ABI.

carrier before replacing exactly these two bodies with includes. Only comments
and whitespace differ. No executable or OMF rewriting occurs. The inherited
CODE/group/near-call contracts and all macros remain in the contextual root.

control flow and independent CPU models. The sources preserve signed remainder,
