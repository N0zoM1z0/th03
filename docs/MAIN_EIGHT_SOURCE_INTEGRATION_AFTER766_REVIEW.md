## Important actual C++ improvements, not just naming constants

Five substantial BOSS sprite render loops no longer manipulate `_AX`
manually. Four compute the original signed top value as
`top = static_cast<screen_y_t>(top >> 4)` while preserving the local
assignment and 16-bit arithmetic. Rikako's extra `ADD AX,-8` is also
naturally generated by `top = static_cast<screen_y_t>((top >> 4) - 8)`.
Separate actual negative TC4 trials rejected the shorter `top >>= 4`
syntax and inlining the shifted coordinate directly as a sprite function
argument: equivalent arithmetic did **not** mean identical original
instructions and stack lifetime.

Rikako Chargeshot's original `_CX` iteration and `_CL` byte-angle
calculation were recovered as a plain signed `register int i`, bounded
four-projectile `for` and `(i << 6) + 0x20`. Other local loop increments
and 0..3 two-way angle parity were also native-exact in the complete
11-function physical source. Its original record sizes, near pointers,
player ownership and Gauge behavior were preserved.

Reimu shared-flight and update/render source now uses natural named
byte-state transitions, signed local loop counters and original Boolean
state tests, compiled as two **separate full original physical TUs**.
The scoped compiler was extended to force the real current `.inl` source
input files and require their actual original native OMF COMENT entries.
The stage-specific source-binding contract is **not retroactive**:
before after765, historical Reimu native receipts did not force those
three included implementation files, so old stage reviewers do not
invent those dependencies. From after765 onward, `ex_rfly` requires both
flight and prefix bodies, and update-only `ex_reup` requires its actual
update body. Seven targeted tests check historical/current guards,
physical owner source paths and the nested source binding. The separate
horizontal/vertical reflection `*= -1` expressions cannot be replaced
with `= -value` in original CODE; native negative controls `af765e`
and `af765f` are retained, with original game semantics left intact.
