# Original DOS strspn: 82-byte counted far-pointer scanner source

The bounded far-cdecl string prefix checker at original CRT member311
is now maintained as readable 8086 source in src/mainl/crt/strspn.asm.
It uses a true four-byte SS local for a far accept-set cursor, preserving
the original ES:BX loads from both far strings and the initial set
pointer restart for each input character. The first absent character
ends the prefix and the AX return is the original 16-bit character
count; the input pointer's original unchecked offset advance is
retained. There is no inserted generic libc behavior, byte table,
NOP padding or binary object patch.

Real native TASM emits **all82 original CODE bytes** byte-for-byte,
with the original one public _strspn at0, empty DATA/BSS, original
literal DATA-before-BSS DGROUP record 08ff02ff03 and zero imported
names or OMF relocations. Multiple earlier true Borland C++ codegen
experiments got the length right but changed the operand-load order
or introduced a spilled character local. The final assembler source
preserves the actual non-spilled far comparison semantics and all
original instruction encodings.

This source is independently assembled at original library position
311 with the previous **19 original source modules**, including
the full 465-byte scantol, both 756/916-byte qsort bosses and
12,622-byte xx. All **873 of893 surrounding CRT member records**
remain untouched. Two genuine TASM/TLIB/TLINK rounds produce the
full **67,372-byte original Japanese decoded MAINL EXE**, its
native MAP and **677 MZ relocation entries** bit-for-bit.
The simultaneous original CODE generated by 20 maintained
source modules is **16,333 bytes**.

The fixed accepted28-provider library, frozen211-owner publication
and pinned original targets are unchanged. This is exact native
source-only working evidence, not new formally accepted ledger
credit. No full cold replay or DIET stage was performed.
