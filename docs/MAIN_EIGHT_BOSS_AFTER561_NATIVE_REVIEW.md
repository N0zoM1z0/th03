# Eight MAIN large boss C++ native source links — after561

This is a native construction, not just another structural probe. The eight
separate natural C++ translation units for Yumemi, Kana, Mima, Reimu,
Kotohime, Ellen, Rikako and Marisa were compiled from independent pinned
ReC98 source materializations twice using the original TC4J flags:

    -c -I. -O -b- -3 -Z -d -DGAME=3 -ml -DBINARY='M'

Unlike the earlier diagnostic-only probes, no spurious global -a2 option was
passed. This retains each original C++ source's own structure packing. The
corrected Marisa test uses the new standalone source-native producer
scripts/probe_th03_main_boss_marisa_native_corrected.py. The historic
scripts/probe_th03_main_boss_marisa_cpp.py remains unchanged because three
repository-local OP/MAINL/ZUN publication gates bind its SHA; editing it
caused demonstrably false publication drift, not a change to the game.
All evidence from the wrong-flag experiments was preserved.

## Independently rebuilt scope

Eight complete original CODE allocations add up to 14,797 bytes across
74 full C++ functions, including large boss update, bullet-pattern and
rendering controllers, and 636 bytes of compiler-generated switch tables.
Each of the 16 emitted objects matches its retained original Borland OMF
stream after normalization of dependency timestamps only. This verifies the
complete non-timestamp source producer, all literal fields and PUBLIC/segment
metadata, rather than merely comparing instruction shapes. All eight
Japanese-target owner CODE ranges also agree with the source-native MAIN image.

Each native round replaces all eight objects simultaneously in the actual
original 99-object MAIN TLINK response. The other 91 objects, C0, compiler
libraries, source/writer order and all held target/reference resources are
reused unchanged. The two independent ordinary TLINK runs both reproduce
the entire 132,322-byte retained native MAIN EXE and its complete
157,164-byte MAP. All 1,553 original ordered MZ relocation entries agree.

Preserved evidence includes both complete round vectors (8 raw OBJ files +
EXE + MAP each), 18 top-level compiler/linker logs, all individual Turbo C++
compiler logs and native source trees, response files, source SHA inputs,
and read-only verification:

## Accuracy limits

Together with Chiyuri's after559 native proof, all nine major BOSS modules
have 17,451 original CODE bytes and 85 complete function bodies bound to
natural C++ and the retained MAIN normal link. These were already-maintained
functions; the source/ledger function counts must not be incremented again
for this verification.

This verifies the selected original native source build, not the full
Japanese original MAIN.EXE identity. The old MAIN MZ header differs, and one
independent load-image byte at EC2D remains different (90h in target versus
00h in native build). This stage therefore does not grant canonical Factory
or whole-game source acceptance. It also does not re-run irrelevant
OP/MAINL/ZUN cold builds or relabel historic accepted extents.
