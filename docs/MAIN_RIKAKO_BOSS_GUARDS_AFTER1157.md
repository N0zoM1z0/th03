# Rikako BOSS: native spin guards and all attack endpoints

The complete BOSS controller now exits an unfinished intro naturally,
leaving the original frame/mode reset after the guard. The orbit-ring,
entity/pellet and alternating-burst families use comparable constant-first
finish predicates. Their three independent eight-frame spin conditions
are expressed as short-circuit conjunctions, retaining the positive,
negative and neutral-spin cases, the RNG order and signed byte mutation.

The `af1157c` original TC4/TLINK proof matches the full 1,677 CODE bytes,
215 ordered native fields and Japanese MAIN image/relocations across two
rounds. A narrower lifetime for the two main-ring polar coordinates was
tried separately at `af1157d`; TC4 generated different CODE, so those
function locals remain in their earlier register/stack allocation scope.
