# TH03 MAIN after639: four BOSS C++ recoveries in 28 original native objects

This is a fresh original Turbo C++ 4.02/TLINK link proof of the current
maintained code, not reuse of the after634 original objects. It includes
genuinely natural C++ recovery of both a large BOSS scheduler and smaller
attacks in four character-specific complete native translation units:

- **Chiyuri:** full 18-mode BOSS dispatch, fan/trailing-ring timing and
  compiler-original `boss_frame % 8` warning cadence and
  `round_or_result_frame % 4` sprite tick in the long update.
- **Rikako:** all three spin cadence paths as `boss_frame % 8`, plus
  the actual compiled signed state update
  `boss_spin_delta += ((boss_spin_delta > 2) ? -1 : 1)`; the full
  mode/attack phase mapping is explicit.
- **Kotohime:** original-equal direct 8-bit `boss_move_phase -= 2`
  in aimed and radial ring routines, and modulo-based 4-frame
  renderer flicker, with four source-readable attack phase groups.
  Direct +2 and -4 expressions were **rejected** on actual CODE mismatch.
- **Kana:** direct C++ angle `+= 6` and pellet speed `+= 3`
  in the staged-ring firing loop, native `boss_frame % 4`
  rotating cadence, plus the large mode and phase dispatcher.
  The four-branch random signed delta and original SUB AL,10h
  byte encoding are preserved after native-unequal alternatives.

The v2 compiler wrapper explicitly names the *staged current* C++
source and, where consumed, the maintained 32-byte BOSS and Extra Attack
