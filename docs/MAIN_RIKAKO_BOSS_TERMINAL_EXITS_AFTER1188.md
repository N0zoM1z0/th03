# Rikako BOSS: three native terminal attack guards

The full Rikako BOSS now returns naturally before the ending tick in each of
its orbit-spread, entity/pellet and alternating burst controllers. The separate
warning and release frames retain their early-return behavior; the random
angle consumed before the entity ring remains, even though its value is
immediately overwritten. The signed spin cadence, four-volley pattern,
integer angular division and sound call order are unchanged.

Stages `af1188a` (orbit), `af1188b` (entities/pellets) and final `af1188c`
(alternating burst) each matched the complete **1,677 CODE bytes**, 215
ordered native fields, eight PUBLICs and the original Japanese MAIN image and
ordered MZ relocations in two independent TC4/TLINK rounds.
