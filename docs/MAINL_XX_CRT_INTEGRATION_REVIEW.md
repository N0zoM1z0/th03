# Integrated original xx plus seven source CRT modules in MAINL

The mainl-xx-crt8 scoped integration combines the independently recovered,
actual native BCC 4.5 exception/RTTI xx object and seven exact natural 8086
CRT source objects, simultaneously occupying eight original positions in
the unchanged original 893-member native library. The eight source members
are: memchr, memcmp, memcpy, memset, strchr, strcmp, strlen and xx.

This is not two unrelated single-member link successes. The integration
extracts the actual 893 original members, retains their original order and
program records, replaces the eight real native objects together, and then
performs two real TLIB/TLINK rounds. The other **885 original member program
records** remain intact. The normal link uses all36 original project objects,
the original startup and emulator/math runtime libraries, and the exact
Japanese target-specific link response order.

The large original xx translation unit contributes **12,622 CODE bytes**
with **all187 literal ordered OMF fields identical**,18 initialized DATA
bytes and10 BSS bytes, all original50 linked procedure bodies,22 native
public definitions and20 ordered MZ words. Its restored high-level source
includes the complete678-byte initCatchArg,880-byte _ExceptionHandler,
1,151-byte RaiseException,582-byte searchBaseClass and357-byte
__DynamicCast. The seven CRT source units contribute a further **329 CODE
bytes** with their original publics,empty native DATA/BSS segments and
original literal GRPDEF grouping. The combined **12,951 source-built CODE
segment bytes** are all verified by the original independent native
producer reports and by the combined reviewer's re-reading of original
native objects; they are not inlined target-byte arrays.

Both integrated source-library rounds produce **the entire fixed
67,372-byte Japanese decoded MAINL EXE, raw-equal to the original**, and
the entire original linker MAP,also raw-equal,including all677 original
MZ relocations. Both complete library/EXE/MAP raw vectors repeat. No
CODE patches,object mutation,raw byte padding,relocation sorting or
relaxed function-size matching are applied. The pinned original target
uses candidate-local-attested provenance.

The builder does not rebuild an unchanged cold/DIET pair and does not
rerun the ancestor runtime chain; it validates the two independent
native source compiler receipts and re-links only the affected library.
It does not overwrite the original accepted28-provider CRT,original
cold outputs or the already published211-owner MAINL accepted ledger.
The working eight-source carrier is **source-exact**, but no additional
formally accepted owner or source-byte credit is published by this scoped
