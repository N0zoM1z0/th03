## Current source recovery in this native graph

- **Yumemi large BOSS**: signed ring delta now writes directly
  to the original byte field without explicit AL assignment.
  Four original ring/aimed/chase cadence masks use natural
  unsigned `%4/%2/%16`, preserving full RNG and attack order
  (individual original-native proof `af665b`).
- **Reimu large BOSS plus renderer leaves**: attack clocks
  use natural modulo; the expanding orbit scales with two
  consecutive natural multiplies `((boss_frame*16)*2)`
  that emit the original x86 sequence. Collapsing this to
  `boss_frame*32` changed CODE and was rejected. Two
  render leaf animation clocks now divide unsigned frame
  by four instead of authoring right shifts (`af666e`).
- **Mima major BOSS**: orbit direction is naturally signed
  C++ direct field assignment; the attempt to remove
  the mode-5-to-2 render goto changed native machine code
  and was rejected (`af667c`).
- **Marisa complete charged-shot/Gauge**: original 50-byte
  physical record, twelve-point history and three-band
  GRCG renderer, natural inactive state checks, named
  24-frame two-sided five-shot Gauge sequence. Signed
  RNG initial Y, and byte speed `-=6`, must keep their
  original forms after native-unequal simplification
  experiments (`af664i`).
- **Player effects**: three small bomb/axis spawners,
  original lifetime updater and large GRCG circle/quad
  renderer are source-rooted, with ordinary C++
  `if(effect->kind)` active checks. Combined age/cursor
  preincrements changed native bytes and were rejected
  (`af668e`).
- **Player warning/Gauge**: six explicitly unsigned
  C++ low-bit parity checks, a natural six-row text-clear
  `for` loop in the large warning state machine,
  and original 27-frame palette flash. PC-98 hardware
  calls and the completion-tick brightness fallthrough
  remain exact (`af669f`).
